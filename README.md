# First API

This project is a simple Express.js backend created as part of the Backend AI Engineering course.

## Features

- Built an Express.js server.
- Created two JSON API endpoints:
  - `GET /`
  - `GET /about`
- Tested both endpoints in a web browser and with `curl`.

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Start the server:

```bash
node index.js
```

3. Open your browser and visit:

- http://localhost:3000
- http://localhost:3000/about
